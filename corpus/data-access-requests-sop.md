# Patient record requests SOP

## Who can request records

A patient can request their own records. A parent or legal guardian can request the records of a child under 18. Anyone else needs the patient's written consent.

## Verifying identity

Check the requester's ID document in person, or a certified copy of it for requests made by email. Never release records or read them out over the phone.

## Response time

Respond within 30 days of receiving a complete request. Log every request in the access request register on the day it arrives.

## Fees

The first copy of a patient's own records is free. Each additional copy costs R100.

## Sending records to another dentist

Only send records to another practice with the patient's written consent. Send them as a password-protected file to the other practice's work email address, and send the password separately by SMS. Never send records by WhatsApp.
